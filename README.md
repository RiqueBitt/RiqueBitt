## 🚀 Meu principal projeto — Project Club

Um dos meus maiores projetos é o **Project Club**, uma plataforma própria inspirada em comunidades e plataformas sociais modernas.

A ideia é criar muito mais do que apenas um site: um verdadeiro ecossistema de comunicação, comunidade, aplicações e serviços.

### 🌐 Project Club

Entre os sistemas que venho desenvolvendo estão:

* 👤 Sistema de contas e perfis
* 👥 Amigos e mensagens privadas
* 💬 Chats e canais
* 🎙️ Chamadas de voz
* 📞 Comunicação em tempo real com WebRTC
* 🏠 Clubes/comunidades
* 🔐 Sistema de permissões e cargos
* 🛡️ Painel administrativo
* 🔔 Notificações
* 🖼️ Fotos, banners e mídia
* 🎨 Temas e personalização
* 🌎 Sistema multilíngue
* 🔒 Recursos de segurança
* 📦 Upload e gerenciamento de arquivos
* 📱 Interface adaptável para diferentes dispositivos

Também estou trabalhando na ideia de transformar o Project Club em uma plataforma que possa possuir seus próprios aplicativos e ferramentas.

### 🧩 Ecossistema de aplicativos

## 🧠 Como gosto de desenvolver

Meu objetivo não é simplesmente fazer algo "funcionar".

Gosto de:

> **Criar → testar → encontrar problemas → corrigir → melhorar → adicionar novas ideias → repetir.**

Também prefiro evoluir sistemas existentes em vez de simplesmente apagar funcionalidades antigas. Quando possível, procuro manter compatibilidade e melhorar a estrutura gradualmente.

Outra coisa que valorizo bastante é a possibilidade de transformar projetos pequenos em sistemas muito maiores com o tempo.
